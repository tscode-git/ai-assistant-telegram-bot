# 📌 О проекте

**AI Assistant Telegram Bot** — это интеллектуальный Telegram-бот, который позволяет пользователям общаться с современными AI-моделями прямо внутри Telegram.

Бот использует **OpenRouter API**, благодаря чему можно подключать разные языковые модели:

* Google Gemini
* OpenAI GPT
* Anthropic Claude
* Llama
* другие модели из OpenRouter

Проект создан как полноценное портфолио-приложение и демонстрирует:

* работу с внешними API;
* разработку Telegram-ботов на Aiogram 3;
* хранение истории диалогов;
* создание inline-интерфейсов;
* управление настройками пользователя;
* асинхронную архитектуру Python.

# 🎛 Inline-меню управления

После команды:

```
/start
```

пользователь получает удобное меню:

```
🤖 AI Assistant

💬 Новый диалог
🧹 Очистить память
🧠 Выбрать модель
📊 Статистика
```

---

# 🧠 Выбор AI модели

Пользователь может менять модель прямо в Telegram.

Доступные модели:

```
⚡ Gemini Flash

🧠 GPT-4o Mini

🚀 Claude Sonnet
```

Выбранная модель сохраняется индивидуально для каждого пользователя.

---

# 🧹 Управление памятью

Бот хранит историю общения.

Команда:

```
/clear
```

или кнопка:

```
🧹 Очистить память
```

удаляет предыдущий контекст.

После очистки:

```
✅ История диалога удалена
```

# ⚙ Установка

## 1. Клонирование проекта

```bash
git clone https://github.com/tscode-git/ai-assistant-telegram-bot.git
```

Переходим в папку:

```bash
cd ai-assistant-telegram-bot
```

---

## 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

# 🔐 Настройка окружения

Создайте файл:

```
.env
```

Добавьте:

```env
BOT_TOKEN=telegram_bot_token

OPENROUTER_API_KEY=openrouter_api_key
```

---

# 🔑 Получение ключей

## Telegram Bot Token

Получить через:

```
@BotFather
```

Команда:

```
/newbot
```

---

## OpenRouter API Key

Создать аккаунт на OpenRouter и получить API ключ.

Добавить:

```
OPENROUTER_API_KEY=ваш_ключ
```

Запуск бота:
